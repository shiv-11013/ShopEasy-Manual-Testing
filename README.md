# ShopEasy E-Commerce Manual Testing Project

## Project Overview

This project focuses on manual testing of the ShopEasy E-Commerce application to identify bugs and verify application functionality.

## Testing Activities

- Requirement Analysis
- Test Scenario Creation
- Test Case Design
- Functional Testing
- Bug Reporting
- Test Execution
- Regression Testing

## Project Files

- **Requirement:** Application requirement screenshots and documents.
- **Bugs:** Screenshots of identified bugs.
- **Test Plan:** Manual testing test plan.
- **Test Scenarios & RTM:** Test scenarios and Requirement Traceability Matrix.
- **Test Cases:** Detailed test cases.
- **Test Execution:** Test execution results.

## Testing Type

Manual Testing

## Tools Used

- Microsoft Excel
- Google Sheets
- GitHub

## Project Objective

To validate the functionality of the ShopEasy E-Commerce application, identify defects, and document testing results.
